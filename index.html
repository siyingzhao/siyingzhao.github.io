BURGER: Benchmarking and Understanding Robotic Generalization via Embodied Drawing

Xiangyu Xu*, Bangshuai Peng*, Ziyi Liu*, Mengjie Zhao*, Chenhao Lu, Zhengyang Fan, Huazhe Xu†, Kaizhe Hu†

arXiv preprint, 2026

* Equal contribution   † Corresponding authors

Website arXiv Code Data

A language-conditioned robotic drawing benchmark. Starting from the same blank canvas, a robot arm draws the object or spatial composition described by language. With 28,200 simulated demonstrations across 282 tasks, we evaluate five representative VLA models on data scaling, language grounding and multimodal behavior, and deploy a trained policy on a real Franka Panda arm.
